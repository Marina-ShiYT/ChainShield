# ChainShield - 智能合约审计系统

## 🛡️ 项目简介
ChainShield 是一个基于 Python 的智能合约静态分析审计工具。它能够自动检测 Solidity 智能合约中的常见安全漏洞。

## ✨ 主要功能
- **自动化扫描**：支持批量上传 .sol 文件进行快速检测。
- **漏洞识别**：能够识别重入攻击 (Reentrancy)、整数溢出 (Overflow)、权限控制缺失 (Access Control) 等多种高危漏洞。
- **详细报告**：生成 JSON 格式的审计报告，定位漏洞代码行。

## 📂 项目结构
- `app.py`: 系统主程序入口。
- `SC01_SC05.sol`: 包含各类典型漏洞的测试合约样本。
- `vuln_rules.json`: 漏洞检测规则库。
- `reports/`: 存放生成的审计报告。

## 🚀 如何使用
1. 确保安装了 Python 环境。
2. 运行 `python app.py` 启动系统。
3. 根据提示输入待检测的合约文件路径。
